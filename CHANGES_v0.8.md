# Dendritron v0.8 Changes

Date: 2026-07-31

## Runnable language core

- Added `DendritronLM`, the two-block recurrent core, signed geometric causal
  mixing, staged memory fusion, working adapters, and geometric output scores.
- Added a margin-ranking objective and a complete CPU tiny-training script.
- Changed cross-token mixing to a bounded local candidate window for practical
  CPU/ARM execution.

## CPU-first frontend

- Added the canonical 259-ID UTF-8 byte tokenizer.
- Changed JTD compilation to use recipient token IDs and made
  `utf8-bytes` the default recipient tokenizer.
- Retained Qwen tokenization as an optional donor-aligned compiler mode.
- Preserved exact phrase text as the permanent cross-tokenizer identity.

## Memory and compute hierarchy

- Added staged layer-8/layer-24 phrase fusion.
- Preserved dictionary sense axes until contextual selection.
- Connected frozen universal directions, shared skill LoRA adapters, and
  skill-adjacent high-dimensional experts to each physical block.
- Added loading of universal direction files generated by the Stage-4 Qwen
  LoRA analysis script.

## Fixed capacity law

- Added an exact 25% memory / 75% conditional-compute ledger.
- Added configuration rejection for ratio drift.
- Added an expert-geometry solver for real completed memory manifests.
- Kept shared recurrent substrate separate from appendable sparse capacity.

## Verification

- 48/48 tests pass on CPU.
- Python compilation succeeds for the runtime and Stage 3–6 scripts.
- A 100-step CPU run reduced tiny-corpus margin loss from 0.459935 to
  0.048951 and produced `artifacts/tiny_dendritron_cpu.pt`.
- Tiny forward latency measured 13.8065 ms median and 14.9875 ms p95.
